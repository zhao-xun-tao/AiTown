# AI Town 模块 1–4 Implementation Plan

> **For agentic workers:** 按任务顺序实现；每任务可独立验证。

**Goal:** 可运行的多层地图 + Y-Sorting + 动画 FSM + 混合 A\*（后端粗路径 + 前端插值/局部重寻路）。

**Architecture:** Spring Boot 推送带 `path` 的 WorldState；Phaser TownScene 多层瓦片与角色 FSM；共享碰撞规则前后端各一份。

**Tech:** Java 17 / Spring Boot 3，Vue3 + Phaser 3，现有 WebSocket。
